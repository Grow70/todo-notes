# 桌面待办便签 🗒️

一款贴在电脑桌面上的轻量待办便签应用。每个便签是一个独立的无边框悬浮窗口，支持拖动、缩放、置顶、多便签管理，数据本地持久化，重启不丢失。

## ✨ 特性

- **常驻桌面** — 无边框透明窗口，紧贴桌面显示，不占用任务栏
- **多便签管理** — 支持同时创建多个便签，每个便签独立的位置、尺寸、置顶状态
- **待办管理** — 添加 / 勾选完成 / 删除，勾选有弹性动效与删除线划过动画
- **持久化** — 数据自动保存到本地 JSON，重启自动恢复
- **置顶 & 缩放** — 一键置顶显示，拖拽边缘自由调整大小
- **双主题** — 宣纸暖白 / 墨黑夜读，「纸墨 · 编辑风」视觉
- **键盘操作** — 全键盘可用（Tab 聚焦 / Space 切换完成 / Backspace 删除）

## 📥 下载与安装

### 环境要求

- 操作系统：Windows 10 / 11（64 位）
- 无需安装额外运行环境，开箱即用

### 下载

前往仓库的 [Releases 页面](https://github.com/Grow70/todo-notes/releases) 下载最新版本，每次发布提供两个文件：

| 文件 | 说明 |
| --- | --- |
| `桌面待办便签 Setup x.x.x.exe` | 安装版（推荐） |
| `桌面待办便签-x.x.x-便携版.exe` | 免安装便携版 |

### 方式一：安装版（推荐）

1. 双击运行 `桌面待办便签 Setup x.x.x.exe`
2. 按向导点击「下一步」，可自定义安装目录
3. 安装完成后，自动在桌面和开始菜单创建快捷方式
4. 从快捷方式启动应用即可

### 方式二：便携版

- 双击 `桌面待办便签-x.x.x-便携版.exe` 直接运行，无需安装
- 适合放在 U 盘随身携带，或不想改动系统注册表时使用

> ⚠️ **首次运行提示**：本应用暂未进行代码签名，Windows SmartScreen 可能弹出「Windows 已保护你的电脑」。请点击「更多信息」→「仍要运行」即可正常使用。

## 🎯 使用说明

### 首次启动

应用启动后会自动生成一个**引导便签**，内含 3 条示例待办，帮助你快速了解用法。

### 新建便签

- 点击便签**右上角的「+」按钮**，或
- 点击**系统托盘图标** → 选择「新建便签」

### 添加 / 完成 / 删除待办

- **添加**：在便签底部输入框输入内容，回车或点击按钮确认
- **完成**：点击待办左侧的**方形复选框**（或选中后按 `Space`），勾选后会有删除线划过动画
- **删除**：点击待办右侧的删除按钮（或选中后按 `Backspace`）

### 移动与缩放

- **移动**：按住便签**标题栏**拖动即可改变位置
- **缩放**：拖拽便签**边缘或四角**任意方向调整大小

位置和尺寸会自动记住，重启后恢复到原位置。

### 置顶与主题

- **置顶**：点击便签上的置顶按钮，让便签始终悬浮在其他窗口之上
- **主题**：点击便签底部的主题按钮，在「宣纸暖白」和「墨黑夜读」之间切换

### 关闭与退出

- **关闭便签窗口**（点右上角 ×）= **删除该便签**，其内容会被清除
- 想要**彻底退出应用**，请通过**系统托盘图标 →「退出」**（应用常驻托盘，关闭所有便签后仍在后台运行）

### 数据保存位置

便签数据保存在系统的用户数据目录（`%APPDATA%` 下的应用文件夹）中的 `notes.json`，卸载应用不会自动删除数据；如需彻底清除，请手动删除该目录。

## 🛠 技术栈

- Electron 31 + electron-vite 2 + Vite 5
- React 18 + TypeScript + Zustand
- electron-builder 打包

## 🚀 开发

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 构建
npm run build

# 打包 Windows 安装包（NSIS 安装器 + 便携版）
npm run dist
```

打包产物在 `note-dist/` 目录：
- `桌面待办便签 Setup *.exe` — 安装器（可选安装目录）
- `桌面待办便签-*-便携版.exe` — 免安装便携版

> 国内网络如遇依赖下载失败，项目已内置 `.npmrc` 配置 npmmirror 镜像，无需额外操作。

## 📁 目录结构

```
src/
├─ main/       # 主进程：窗口管理、JSON 持久化、托盘、IPC
├─ preload/    # 桥接层：contextBridge 暴露 noteAPI
└─ renderer/   # 渲染进程：React 便签 UI
```
